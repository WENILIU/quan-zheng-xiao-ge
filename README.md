# 權證小哥 當沖重點與策略(回測整理版)

> 來源:雅筑會客室訪談「權證小哥」逐字稿。本文件將口語內容轉為可判定規則,供回測 agent 使用。
> 標記:`[可量化]` = 可直接寫成回測條件;`[需定義]` = 需先定義計算方式才能回測;`[觀念]` = 心法,不直接回測。

---

## 1. 當沖標的篩選條件

- `[可量化]` 日均成交量 >= 3,000(基本門檻);3萬/5萬/10萬以上更佳。
- `[可量化]` 波動幅度要大:優先挑「前一天大漲/漲停」的標的。
  - 前一天「無量漲停」-> 隔天大概率仍偏強(續航機率較高)。
  - 前一天「爆量漲停」或「爆量長紅」-> 隔天波動大(隔日沖要出貨、出貨前會誘多)。
- `[可量化]` 熱門題材:選當下成交量/波動集中(資金關注)的族群。
- `[需定義]` 範例標的:00981A(量大、波動不算大但有大行情時因量體大好做)。

## 2. 強勢股「續航力」判斷

- `[可量化]` 月線向上且斜率陡峭(「很抖」)+ 股價沿布林上軌 -> 極強,持續天數不確定。
- `[可量化]` 布林通道走平或向下 + 月線向下 + 大長紅漲停 -> 通常只強 1~2 天。
- `[觀念]` 部分強勢股僅能強一天;不要假設一定持續。

## 3. 當沖資格與成本(環境參數)

- 現股當沖資格:開戶滿 3 個月 + 今年成交 >= 10 筆 + 簽署風險預告書。
- 資券當沖資格:今年成交金額 >= 25 萬 + 開信用交易帳戶。
  - 建議現股+資券都開:先賣若被鎖漲停又無券,需借券(借券費+手續費+隔天跳空)常賠大;有資券可改個券。
- `[可量化]` 手續費:千分之 1.425(量大可議價,月上億約可談到 2~3 折)。
- `[可量化]` 證交稅:現股當沖 千分之 1.5(一般 千分之 3,當沖有打折)。

## 4. 核心心法(反向情緒)

- `[觀念]` 主力邏輯:主力想買會讓你想賣;主力想倒貨會讓你想要買。盤中「與情緒為敵」-- 你想買時往往是該賣的時機。
- `[觀念]` 散戶最常犯的錯:追高買在情緒高點、恐慌砍在低點、靠情緒而非數據下單。
- `[可量化]` 用數據判斷轉折,取代情緒下單(見第 5、6 節訊號)。

## 5. 籌碼與節奏

- `[可量化]` 每天研究籌碼:基本面變化小、籌碼變化大(需導入籌碼面數據,如三大法人/自營商/隔日沖相關)。
- `[需定義]` 節奏(紅黑交替):K 棒一紅一黑(紅黑紅黑)= 主力一買一賣。若已連續看到 ~10 次紅黑交替,紅棒隔天再做多是錯誤訊號。
- `[需定義]` 節奏(連紅):紅紅紅紅沿五日線上漲,通常某天出現長黑;連紅越久越接近反轉(且可能接近被關/處置)。

## 6. 連次量(核心訊號)

- `[需定義]` 連次量:權證小哥自有軟體(永豐大戶/閃電下單)指標,統計「連續若干盤中週期量能連續由同一方勝出」的次數,以紅/綠亮燈呈現(範例數字:十次、203)。回測前需先重建此指標的計算規則(建議:連續 N 根 K 線成交量 > 門檻且價格同向)。
- `[需定義]` 連次量「兩個都亮燈」+ 急拉 + 該股有隔日沖 -> 容易轉折向下。
- `[需定義]` 連次量轉綠 + 急殺 -> 容易反彈。
- `[可量化]` 紅燈計數代表多方連續獲勝次數;越漲,買氣越可能衰竭 -> 紅燈轉綠的瞬間視為轉折候選。

## 7. 爆量竭盡法則(進出場規則)

- `[可量化]` 空頭訊號「空在爆量漲不動」:出現大量但價格漲不上去(量增價不漲) -> 買盤竭盡 -> 準備做空。
- `[可量化]` 多頭訊號「買在爆量跌不動」:大量殺低但價格跌不下去(量增價不跌/止穩) -> 賣盤竭盡 -> 準備做多。
- `[可量化]` 均量比 = 當日成交量 / 平常(基準期)平均量,衡量今日量能放大倍數。

## 8. 風險與教訓(回測需納入的約束)

- `[觀念]` 最慘情境:當沖套牢不賣 -> 賠錢變存股 -> 遇處置/被關 -> 續跌。回測務必設「當日平倉(不隔日)」硬規則。
- `[需定義]` 處置/風控事件會限制交易,需作為交易限制條件輸入。

## 回測落地建議(給 agent 的操作化清單)

直接可測(優先實作):
1. 標的池過濾:日均量 >= 3000(可調)、前一日漲停/大漲、波動率排名。
2. 進場訊號:量增價不漲 -> 空;量增價不跌/止穩 -> 多。
3. 續航分類:月線斜率 + 布林上軌位置(強/弱)。
4. 成本模型:手續費 0.1425%(可設議價後)、當沖證交稅 0.15%。
5. 硬風控:当日收盤前強制平倉(不隔日)。

需先定義再測:
6. 「連次量」指標:明確定義週期(如 1 分鐘 K)、量能門檻、同向判定、連續計數、紅/綠燈規則。
7. 「急拉/急殺」:定義盤中漲跌幅速率門檻。
8. 「均量比」基準期:選 5/10/20 日均量當基準。
9. 節奏(紅黑/連紅)計數規則。
10. 處置/借券等交易限制如何建模。
